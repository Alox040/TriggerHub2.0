# Product Overview

## Product
TriggerHub 2.0

## Current Stage
Early-stage Windows desktop product for creator and stream workflow automation. The repository shows a real technical foundation with implemented trigger and macro engines, desktop packaging, app facade wiring, and a plugin registry base, but several user-facing and integration-heavy areas remain incomplete.

## Core Problem
Creators and streamers lose time and reliability when repetitive workflow steps are spread across multiple tools and handled manually during live operation.

## Current Product Direction
TriggerHub aims to provide a desktop control layer where trigger, condition, and action chains can automate creator workflows from one place.

## Supported Product Truth Today
- Trigger and macro runtime exists.
- Windows desktop packaging exists.
- Dashboard runtime data is partially connected through the app facade.
- Plugin architecture groundwork exists.

## Not Yet Mature Enough To Market As Complete
- fully production-ready OBS integration
- Spotify OAuth-based integration
- real clip capture workflow
- complete editor, settings, and plugin management UX
- plugin marketplace or team/cloud product

## Current GTM Implication
Marketing should position TriggerHub as an early-stage creator automation hub for technically comfortable early adopters, not as a finished broad-market platform.
