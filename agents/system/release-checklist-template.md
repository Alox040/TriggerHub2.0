# Release Checklist Template

## Scope
- Welche Änderungen Teil des TriggerHub-Releases sind.

## Qualität
- Tests abgeschlossen.
- Bekannte Risiken dokumentiert.
- Quality Gate bewertet.

## Delivery
- Build-Artefakte erstellt.
- Version aktualisiert.
- Release Notes vorbereitet.

## Rollout
- Kanal und Zielgruppe festgelegt.
- Monitoring bereit.
- Rollback-Pfad bestätigt.
