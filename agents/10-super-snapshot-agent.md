# Super Snapshot Agent

## Purpose

Create a complete technical snapshot of the project including:

- project overview
- architecture
- agent system
- workflows
- development state

The output is intended for AI context, documentation and planning.

---

## Responsibilities

The agent must:

1. Scan the entire repository
2. Detect all agents
3. Analyze architecture
4. Identify workflows
5. Generate structured documentation

---

## Analysis Scope

### 1. Project Overview

Extract:

- project name
- purpose
- main modules
- platform targets

---

### 2. Repository Structure

Generate a simplified directory map of the repository.

Focus on:

- core application
- website
- agents
- services
- tools
- tests

---

### 3. Architecture Analysis

Identify:

- macro system
- event system
- plugin system
- UI structure
- service layer
- deployment pipeline

Summarize how these systems interact.

---

### 4. Agent System Analysis

For every agent detected:

Extract:

- agent name
- file location
- purpose
- trigger mechanism
- dependencies
- related workflows

---

### 5. Workflow Analysis

Detect automation workflows including:

- release pipeline
- deployment
- website sync
- security audit
- snapshot generation

Explain how the workflows interact.

---

### 6. Development Status

Identify:

- implemented systems
- partially implemented systems
- missing components
- possible technical risks

---

## Output Files

The agent must generate the following files:

docs/PROJECT_SNAPSHOT.md

docs/PROJECT_DEEP_SNAPSHOT.md

docs/AGENT_SYSTEM_MAP.md

docs/WORKFLOW_GRAPH.md

docs/DEV_STATUS.md

---

## Output Requirements

Documents must be:

- structured
- concise
- AI-readable
- developer-readable
