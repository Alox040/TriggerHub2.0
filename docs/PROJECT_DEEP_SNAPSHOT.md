### Event -> Trigger -> Action -> Macro Flow
1. Event is published via `InMemoryEventBus`.
2. `TriggerEngine` resolves triggers by topic from `TriggerGraph`.
3. Conditions are evaluated (`evaluateCondition`).
4. Actions dispatch through `TriggerExecutor`.
5. Executor handlers call service actions or `macro.run`.
6. `MacroEngine` executes typed steps and can recurse through `macro_call`.
7. Completion events are re-published (`TRIGGER_EXECUTED`, `MACRO_COMPLETED`).
8. UI subscribes to completion events and refreshes dashboard state through facade.
