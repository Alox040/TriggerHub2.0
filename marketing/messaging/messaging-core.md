## Product Reality Baseline
TriggerHub is currently a Windows desktop prototype for creator automation. The strongest implemented areas are the trigger engine, macro system, app facade, plugin registry infrastructure, test coverage, and desktop packaging. UI coverage is partial, and real-world integrations are not yet fully production-ready.

## Messaging Pillars
### 1. Automation over manual tool switching
TriggerHub is about turning repeated creator actions into reusable trigger and macro flows instead of relying on scattered manual steps.

### 2. One desktop control layer for creator workflows
The product direction is a single desktop hub that can eventually coordinate stream, media, clip, and plugin workflows from one place.

### 3. Built with extensibility in mind
The architecture already includes a plugin registry and modular service boundaries, which supports a credible future expansion story.

### 4. Early access shaped by real workflow feedback
The product is still in an implementation-heavy stage, so the strongest marketing angle is focused iteration with early creators rather than broad feature breadth.

## Creator Target Segments
### Primary Segment: Automation-minded streamers
- Solo creators who run live streams on Windows
- Comfortable with tooling and setup work
- Feel friction from repetitive stream actions and context switching

### Secondary Segment: Power users with repeatable creator workflows
- Creators who want triggerable routines for scenes, playback states, clips, and stream support tasks
- Likely to value reliability, visibility, and future extensibility over polished breadth today

### Future Segment: Plugin-oriented creator teams
- Small creator teams or technical collaborators
- Relevant later, once the editor, real integrations, persistence, and plugin ecosystem mature

## Positioning
TriggerHub is an early-stage desktop automation hub for creators who want to replace repetitive live workflow steps with structured triggers and macros.

## Key Value Propositions
- Reduce repeated manual actions by organizing workflows around triggers and macros.
- Centralize creator automation logic in one Windows desktop app instead of scattered tool switching.
- Start from a technically credible foundation with tested core automation logic and packaged desktop distribution.
- Grow into more advanced workflows over time through a modular architecture and plugin-ready direction.

## Safe Product Claims
These claims are supported by the current repository state and can be reused in marketing drafts:
- TriggerHub has a working trigger engine and macro execution system.
- TriggerHub ships as a Windows desktop application built with Electron.
- The current codebase includes a plugin registry foundation for future extensibility.
- The dashboard is partially connected to live runtime data through the app facade.
- TriggerHub is in an early product stage and still expanding real integrations and user-facing workflows.

## Claims To Avoid
- Do not claim full production readiness.
- Do not claim native live OBS WebSocket support is complete.
- Do not claim Spotify OAuth is implemented.
- Do not claim screen clip capture is fully real-world ready.
- Do not claim a usable plugin marketplace or plugin installation flow exists.
- Do not claim the editor, settings, or plugin management UX is complete.
- Do not claim broad team, cloud sync, or marketplace features.
