Design a modern desktop interface for a streaming control application called TriggerHub.
The software is used by streamers to control scenes, triggers, apps, and automations during live streams.

Design Goals

The interface should feel young, modern and energetic, but still clean and professional.

Avoid overly dark cyberpunk styles or heavy neon gamer aesthetics.

Use a light or soft-dark UI theme that is easy on the eyes during long streaming sessions.

The design should feel playful but efficient, similar to tools used by creators (Notion, Discord, Stream Deck UI).

Color Direction

Main base color: soft dark grey or muted neutral background

Accent colors: green, teal, or soft blue

Small highlights: subtle red or orange for active states

Avoid high-contrast pure white backgrounds

Typography

Modern sans-serif font

Clear hierarchy for quick recognition during live streaming

Large readable buttons for fast interaction

Layout Structure
Create a modular control dashboard with these areas:

Sidebar Navigation

Dashboard

Scenes

Triggers

Automations

Apps

Settings

Main Control Grid

Large trigger buttons similar to a Stream Deck

Each button can show icon + label

Active states should be clearly visible

Automation Panel

Visual blocks showing connected triggers

Simple workflow visualization

Activity / Status Bar

Shows running triggers

Connection status (OBS / Twitch / Apps)

UI Characteristics

Rounded corners

Soft shadows

Clear hover states

Smooth spacing and padding

Modular components that could scale into future features

Interaction Feel
The interface should feel fast, tactile and responsive, allowing streamers to control everything without thinking during a live broadcast.

Overall Mood
Creator-focused software that feels fun to use but powerful, like a professional streaming cockpit.
