# Design Prototype

Dieses Verzeichnis enthaelt einen separaten Design- und Prototyp-Stand fuer TriggerHub 2.0.

## Rolle im Repository

- Design-Referenz und UI-Prototyp
- kein produktiver Einstieg fuer Desktop oder Website
- Vorlage fuer Layout-, Komponenten- und Interaktionsideen

## Herkunft

Die Basis stammt aus einem Figma-Codebundle:
https://www.figma.com/design/3SAWuZ27BIJJWLbzAamf2b/Dashboard-Layout-Variations

## Lokale Nutzung

- Abhaengigkeiten installieren: `npm install`
- Dev-Server starten: `npm run dev`
- Produktionsbuild erzeugen: `npm run build`

Vom Repo-Root aus laesst sich der Prototyp ueber `npm run design:dev` starten.
